# Mock Coding Test 1

This is a new practice test based on the topics and question styles from the
official example. It is not a copy of the real test and does not contain secret
questions.

## Test rules

1. Allow yourself 90 minutes.
2. Answer Groups 1 and 2 on paper without running the files.
3. Do not use notes, autocomplete, or the internet.
4. For every answer, check spelling, indentation, colons, brackets, and types.
5. Only after 90 minutes, type or run your answers to check them.

## Order and timing

| Time | Work |
| --- | --- |
| 15 minutes | `01_trace.py` |
| 20 minutes | `02_debug.py` |
| 20 minutes | `03_complete.py` |
| 35 minutes | `04_programming.py` |

Do not look for solutions before attempting every question. When you finish, ask
for a review and explain your reasoning; do not send only the final output.
