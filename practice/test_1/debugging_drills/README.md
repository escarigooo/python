# Debugging drill bank

These 20 exercises cover the syntax and mistakes expected through Week 7. Every
file contains the complete question, faulty code, and expected behaviour. The
solutions are intentionally not included.

## How to answer each question

Before changing the file, write these three things on paper:

1. the faulty line or lines;
2. why each line is wrong;
3. the corrected line or lines.

Then edit the program and run only that file. A program is finished when it works
for the example and also for a different input that you invent.

## Recommended order

- `easy/`: one common mistake per exercise;
- `medium/`: loops, strings, and lists with several related mistakes;
- `exam/`: mixed questions similar to a handwritten test.

Do Exercises 1-6 first. Send your corrections for review before moving to medium.
