# Project inspiration and further reading

The code in this folder was written specifically for this course and was not copied
from these repositories. The repositories are useful examples of how small programs
can teach larger programming ideas.

- [PythonStdioGames](https://github.com/asweigart/PythonStdioGames) collects games
  that work through standard text input and output. This inspired the terminal-only
  format used here.
- [The Big Book of Small Python Projects](https://github.com/asweigart/the-big-book-of-small-python-projects)
  contains many compact projects, including Bagels and Conway's Game of Life. It
  inspired the Codebreaker and Game of Life project choices.
- [Free Python Games](https://github.com/grantjenks/free-python-games) is an
  educational collection of independent games. Its projects are graphical and more
  advanced than the current syllabus, so only the learning-by-changing-a-game idea
  is used here.
- [TheAlgorithms/Python](https://github.com/TheAlgorithms/Python) contains readable
  algorithm implementations and a cellular-automata section. It is a useful next
  reference after you can explain this folder's Game of Life program.
