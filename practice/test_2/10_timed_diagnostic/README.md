# 30-minute diagnostic: Coding Test 2

This mock checks the course topics released through Week 12: `while` and `break`,
nested loops, list comprehensions, matrices, functions, parameters, `return`, scope,
and list mutation. It is practice for the second midterm and final exam, not a copy
of an exam paper.

## Set up

Use a timer for exactly 30 minutes. Work on paper without running Python or opening
the solutions. If you get stuck, leave space and move on. Use `answer_sheet.md` or a
blank page. Open `test.md` when ready; check `solutions.md` only after time is up.

| Part | Time | Points |
| --- | ---: | ---: |
| 1. Trace and choose | 6 min | 6 |
| 2. Find and fix | 6 min | 4 |
| 3. Fill the blanks | 3 min | 3 |
| 4. Write a small program | 15 min | 7 |
| **Total** | **30 min** | **20** |

After grading, record the question numbers you missed and use the review map at the
bottom of `solutions.md` to choose what to practise next.
