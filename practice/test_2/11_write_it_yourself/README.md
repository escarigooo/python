# Write it yourself

These are coding prompts, not an answer key. Each prompt has its own `.py` file.
The first three files now contain attempts from our practice together; for another
round, cover the code and recreate it from memory before checking it.

## How to practise

1. Open the first file and read only its prompt.
2. Write the code from memory before searching notes or examples.
3. Run it and compare your output with the prompt.
4. If it fails, fix your own code and try again.
5. Send me your attempt when you want feedback. I’ll review the code you wrote and
   give a hint before showing a full solution.

The week column gives the main course week for the new syntax; earlier topics may
also be used as prerequisites. The same week and difficulty labels appear inside
each Python file.

Difficulty is relative to the professor's practical exercises: 1/5 is a short
syntax drill, while 5/5 matches the hardest integrated exercises such as Week 11
Exercise 4 (matrix addition) or Week 12's `flip` recap. See the
[hardest-practical review](../HARDEST_PRACTICAL_REVIEW.md) for those examples.
